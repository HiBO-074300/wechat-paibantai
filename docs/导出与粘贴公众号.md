# 导出与粘贴公众号

排版台有 6 种输出方式，都基于同一份导出结果：**全篇一个 `.wrap` 容器，所有样式内联写在标签上，不带 class 依赖**。所以粘到哪里都不会因为"样式表没跟过去"而掉版。

## 六种方式怎么选

| 方式 | 入口 | 产物 | 适合 |
| --- | --- | --- | --- |
| 复制到公众号 | 顶部按钮 / `Ctrl + Shift + C` | 富文本（`text/html` + `text/plain`） | 日常发文，直接粘进公众号编辑器 |
| 复制 HTML | 导出弹窗 | 纯 HTML 源码 | 贴到支持 HTML 的地方，或存档备用 |
| 复制纯文本 | 导出弹窗 | 文字（图片只留图注） | 发到不支持富文本的地方 |
| 下载 .html | 导出弹窗 | 一个独立网页文件 | 本地预览、发给别人看效果 |
| 导出 Word | 导出弹窗 | `.doc` | 需要在 Word 里继续改稿 |
| 导出 PDF | 导出弹窗 / `Ctrl + P` | 打印窗口 → 另存为 PDF | 定稿存档、打印 |

## 复制到公众号是怎么实现的

优先走浏览器剪贴板 API 写入富文本（`ClipboardItem`，同时带 `text/html` 与 `text/plain`）；浏览器不支持时，退回到一个隐藏的 `contenteditable` 容器 + `document.execCommand('copy')`。

因此：

- 在 `https`（GitHub Pages 等）和 `http://localhost` 下最稳；
- 用 `file://` 双击打开时，部分浏览器会拦截富文本写入，请改用「导出 → 复制 HTML」。

粘贴后如果公众号编辑器去掉了某些样式，是它的二次处理，属于平台行为，不是导出内容缺失。

## PDF 导出的行为

点「导出 PDF」会打开系统打印窗口，选「另存为 PDF」即可。打印时会：

- 隐藏工具栏、底部输入区、左右两栏，**只输出正文**；
- 去掉手机外壳的边框与阴影，正文按纸张宽度排版；
- 页面标题会临时改成工程名，方便打印窗口默认用它当文件名；
- 页边距为 `18mm × 16mm`（在打印预览里也可自行调整）。

## Word 导出的行为

生成的是"HTML 版 `.doc`"（带 Office 命名空间与 `@page` 设置），Word、WPS 都能直接打开并继续编辑。首次打开时 Office 可能提示"文件格式与扩展名不一致"，选择"是"即可正常打开。

## 导出内容长什么样

以一段正文为例（开了首行缩进，内容有三行）：

```html
<p style="margin:14px 0;text-indent:2em;">第一行</p>
<p style="margin:0;text-indent:2em;">第二行</p>
<p style="margin:0;text-indent:2em;">第三行</p>
```

第一段保留上下间距，后续段落 `margin:0`，所以整体行距和一段文字完全一致，但每一行都缩进两个字符。

图片模块：

```html
<p style="margin:18px 0;line-height:0;text-align:center;">
  <img src="/uploads/demo.png" style="max-width:100%;height:auto;display:inline-block;vertical-align:top;" alt="图注文字">
</p>
<p style="margin:8px 0 0;font-size:14px;line-height:1.6;color:#8C8C8C;text-align:center;">图注文字</p>
```

对齐写在外框 `text-align` 上，图注沿用同一对齐。

## 粘贴到公众号前的检查清单

1. **图片地址可公开访问**：图床或自建站点的线上地址，不要用本机路径、内网地址或只在你自己浏览器里有效的 `blob:` 地址。
2. **字号别太小或太大**：正文 15–17px 在手机上最舒服。
3. **标题层级别滥用**：一篇文章一个 H1 就够，H2 分章节，H3 收小节。
4. **首行缩进与段间距二选一**：中文排版常见做法是"首行缩进 + 段落不额外留白"，或者"不缩进 + 段间留白"；两者同时拉满会显得松散。
5. **先粘再微调**：公众号里的最终效果才算准，粘贴后按需改一两处即可。

## 常见问题

**粘贴后图片是个红叉 / 空白？**
地址不可访问（本地路径、内网、失效链接）。换成线上地址，或先把图片上传到能公网访问的地方。

**样式对，但标题的字体跟预览不一样？**
预览用的字体（如 `Songti SC`）在你读者手机上不一定存在，浏览器/微信会回退到默认衬线字体。想完全可控，请选通用字体族（如 `serif`、`sans-serif`）。

**代码块被压扁了，没有横向滚动？**
公众号会去掉 `overflow-x:auto` 这类声明。长代码建议手动换行，或截成图片。

**文字挤在一起，行距变了？**
可能是公众号给容器加了行高。可以在样式面板里给 `.wrap` 提高 `line-height` 重新覆盖。
