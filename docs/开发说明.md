# 开发说明

给要改代码的人（包括几个月后的自己）。项目是**单个 `index.html`**，无框架、无构建、无依赖，所有代码在文件末尾的一个 `<script>` 里，按功能分了 10 段。

## 代码地图

```
index.html
├─ <style>   设计令牌（:root 变量）→ 顶栏/模块/预览/底部/弹窗样式
├─ <body>    窗口栏 · 工具栏 · 三栏 main.app · 底部排字盘 · 回收站 · toast · 三个弹窗
└─ <script>
     1.  类型定义        TYPES / isContainer / canAlign / canIndent / alignKeys
     2.  数据模型        state、树工具（listOf / findParent / detach / subtreeContains）
     2b. 工程文件        保存与打开 .ptai.json
     3.  渲染            renderAll / renderList / renderBlock / fmtBarHtml / updatePreview
     4.  导出样式与输出  S、exportHtml、fullHtml、fmtOf、indentParas、imgHtml
     5.  操作            增删改、换版式、对齐、缩进、移动
     6.  拖拽            指针事件 + 指示线 + 自动滚动
     7.  交互事件        全局事件委托（click / change / input / keydown）
     8.  底部排字盘      新建模块
     9.  弹窗与导出      换版式 / 导出 / 样式 / 复制到公众号 / Word / PDF
     9b. 窗口栏          工程名、保存状态、收起工具栏、全屏
     10. 其它            toast、重置、启动
```

## 数据模型

模块数据是一棵树，全部挂在全局 `state` 上：

```js
state = {
  blocks: { k1:{…}, k2:{…} },   // id -> 模块
  pool:   ['k3'],                // 模块池的顶层 id 数组
  article:['k1','k2'],           // 文章结构的顶层 id 数组
  open:   { k1:true },           // 展开状态（不进导出）
  name:   '未命名推文',           // 工程名
  css:    ''                     // 用户在样式面板里写的 CSS 文本
}
```

单个模块：

```js
{
  id:      'k1712345678_3',
  type:    'p',                  // 见 TYPES
  content: '文字内容',            // 容器类模块里存的是名称
  children:[ 'k4', 'k5' ],       // 仅。组合 / 复合有
  align:   'center',             // 可选：left | center | right | justify
  indent:  true                  // 可选：首行缩进
}
```

树工具：

- `listOf(cid)` 取某容器（`'pool'` / `'article'` / 模块 id）的 id 数组；
- `findParent(id)` 反查父容器；
- `detach(id)` 从任意位置摘下来；
- `subtreeContains(root, target)` 防止把容器拖进自己内部。

**改数据后统一走三件套**：`pushHistory()` → `renderAll()` → `save()`。漏掉第一个就没法撤销，漏掉最后一个刷新就丢。

## 渲染

`renderAll()` 会记住各列表的滚动位置，重建模块池与文章结构，然后刷新统计、预览、多选条、折叠按钮。`renderList()` 负责空态，`renderBlock()` 递归生成一行模块：

- 行内：拖拽把手、展开三角、色块、类型标签、标题、折叠摘要、字数 / 格式标记、勾选 / 换版式 / 拆分 / 复制 / 删除按钮；
- 展开体：容器给名称输入框 + 子容器 + 新建子模块；普通模块给 `<textarea>` + 格式条 `fmtBarHtml()`；分割线给只读框；图片模块额外给上传行。

**预览即导出**：`updatePreview()` 直接调 `fullHtml()` 塞进右栏，所以样式、对齐、缩进在预览里看到的和粘出去的一致。

就地小更新用 `syncFmt(id)`（只改按钮态和行尾摘要），避免整页重渲染导致输入框失焦。

## 导出管线

```
state
 └─ fullHtml()            包一层 <section style="…S.wrap…">
     └─ exportHtml(b)     按类型生成标签，样式 = S.xxx + fmtOf(b)
         └─ fmtOf(b)      段内格式：text-align / text-indent
```

- `S` 是"选择器名 → 声明字符串"的字典，导出时把声明内联进标签的 `style`；
- `fmtOf(b)` 只输出非默认的段内格式，保持 HTML 干净；
- 特殊处理：`hf`（H2 非左对齐时去掉色条）、`indentParas()`（多行 + 缩进 → 一行一个 `<p>`）、`imgHtml()`（图片 + 图注）、`composite` 不套外壳、`group` 套 `S.box`。

**样式面板链路**：`S_DEFAULT` 保存出厂快照 → `parseCssInto(S, state.css)` 把用户 CSS 覆盖上去 → `refreshCss()` 在启动、打开工程、撤销、重置后重新计算，并顺手把样式值里的双引号换成单引号（防 `style="…"` 被截断）。`CSS_ORDER` 决定面板里的排列顺序，`CSS_NOTE` 是每个选择器的中文说明。

## 工程文件格式（`.ptai.json`）

```json
{
  "app": "paibantai",
  "version": 1,
  "name": "示例推文",
  "savedAt": "2026-10-08T02:30:00.000Z",
  "css": "",
  "blocks": {
    "k1": { "id": "k1", "type": "h1", "content": "标题" },
    "k2": { "id": "k2", "type": "p", "content": "正文\n第二行", "indent": true }
  },
  "pool": [],
  "article": ["k1", "k2"],
  "open": { "k1": true }
}
```

打开时会校验 `blocks` 存在且 `article` 是数组，不合法就提示"这不是排版台工程文件"。`examples/示例工程.ptai.json` 是一个可直接载入的完整例子。

## 加一种新模块（以「视频」为例）

**第一步：声明类型**（第 1 段）

```js
const TYPES = {
  …
  video: { label:'视频', name:'视频模块', desc:'第一行视频地址，第二行起说明' },
};
```

加完立刻会出现在底部下拉和「换版式」弹窗里。想让它有独立配色，在 CSS 里补一行：

```css
.blk.t-video{ --tc:#8E44AD; }
```

**第二步：定义它能设哪些格式**（第 1 段）

```js
const canAlign  = t => !isContainer(t) && t !== 'hr';       // 一般不用改
const canIndent = t => t === 'p' || t === 'strong';          // 只给正文型
const alignKeys = t => t === 'img' ? ['left','center','right'] : ALIGN_KEYS;
```

比如视频只有左/中/右，就在这里加一条判断。

**第三步：展开体控件**（第 3 段 `renderBlock`）

普通文本型模块直接就有 `<textarea>` + 格式条，不用写代码。需要额外控件时加分支，并用 `data-act` 走事件委托：

```js
: b.type === 'video'
  ? `<textarea placeholder="第一行视频地址…">${esc(b.content)}</textarea>${fmtBarHtml(b)}
     <div class="imgup"><button data-act="pickvideo">选择视频</button></div>`
  : …
```

然后在第 7 段的 `click` 委托里加 `else if (act === 'pickvideo'){ … }`，需要读文件就再加一个 `change` 委托（参考图片上传那段）。

**第四步：导出 + 样式**（第 4 段）

```js
case 'video': return `<p style="${S.videobox}${f}"><video src="${esc(src)}" style="${S.video}"></video></p>`;
```

并在 `S` 里加默认值，同时补 `CSS_ORDER`、`CSS_NOTE` 和样式弹窗里的选择器清单文案（三处都要，否则用户在样式面板里看不到它）。

最后用 `examples/示例工程.ptai.json` 加一个视频模块，验证：能新建、能拖拽、能设位置、预览正确、导出 HTML 结构正确、撤销能回退。

## 调试技巧

**直接在控制台里玩数据**。所有函数和 `state` 都是全局的：

```js
state.article                    // 当前文章结构
state.blocks['k1']               // 看某个模块
fullHtml()                       // 看导出结果
snap()                           // 看自动存档的 JSON
JSON.stringify(buildProject())   // 看工程文件内容
```

**无头浏览器做回归**。往 `index.html` 末尾注入一段脚本，把结果写到 `body` 属性上，再用无头浏览器 dump 出来比对，适合验证导出这种纯函数逻辑：

```powershell
# 注入：state.blocks={}; …; document.body.setAttribute('data-result', fullHtml());
msedge.exe --headless=new --dump-dom "file:///C:/path/to/test.html" > dom.txt
```

**改样式类问题的自查顺序**：样式值里有没有双引号 → 预览里生效了吗 → 导出的 HTML 里那条声明在不在 → 有没有排在 `font-family` 之后被截断。

## 版本与分支约定

- `main` 分支保持可用：任何时候 clone 下来双击 `index.html` 都能跑；
- 一次 PR 只做一件事，提交信息用 `feat:` / `fix:` / `docs:` / `style:` 前缀；
- 版本号按语义化版本推进，并同步更新 `CHANGELOG.md`。
