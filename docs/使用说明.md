# 使用说明

排版台是一个单文件网页应用，打开 `index.html` 就能用。整体思路是：**先把内容拆成模块，再靠拖拽排版，样式最后统一调**。

## 界面：三栏各管什么

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 模块池 | 左栏 | 备用素材。写好的段落先丢这里，想到放哪再拖进文章 |
| 文章结构 | 中栏 | 正文的树。拖动排序、收纳进组合、拖到右下角回收站删除 |
| 公众号预览 | 右栏 | **就是导出结果**，所见即所得；改样式、改对齐立刻反映在这里 |

顶部工具栏：撤销 / 重做 / 保存工程 / 打开工程 / 样式 / 重置 / 导出 / 复制到公众号。

窗口栏（最上面那条）可以改工程名，双击空白处可收起顶部工具栏，让编辑区更大。

## 第一步：往文章里放内容

底部「＋ 新建模块」区：

1. 下拉选版式（正文、H2、引用、图片…）；
2. 中间的输入框写内容。列表类（无序 / 有序）**每行一项**；
3. 选目的地：`放入模块池` 或 `排到文章末尾`；
4. 点「排入」，或直接按 `Ctrl + Enter`。

> 图片模块可以先建空的，之后再上传或填地址。

## 第二步：拖拽排版

- **拖模块行**（左侧点阵把手那一行）上下移动，跨栏、跨层级都行；
- **拖进虚线框** = 收进「组合」里，支持继续嵌套；
- **悬停**在某个组合上约 0.35 秒会自动展开，方便往里放；
- 拖到靠近列表边缘会自动滚动；
- **拖到右下角回收站**删除；
- 想调整位置也可以聚焦模块行后按 `Alt + ↑ / ↓`。

## 第三步：设段内格式（对齐、缩进、图片位置）

点模块左边的三角展开，底部会出现格式条：

- **对齐**：左 / 居中 / 右 / 两端对齐。标题、正文、引用、列表都能设。
  - H2 默认带一根左侧色条，改成居中或右对齐时会自动去掉，避免"看着没居中"。
- **首行缩进**：只给「正文」和「重点」。打开后缩进 2 个字符；**如果内容里有换行，每一行都会缩进**。
- **图片模块的格式条叫「位置」**：居左 / 居中 / 靠右（图片没有两端对齐）。

设置会以小标签形式显示在模块行右侧（例如 `居中`、`缩进`），一眼能看出哪些模块改过。

## 图片模块怎么用

展开图片模块后：

- **第一行**填图片地址：可以是图床/自建站点的绝对地址（`https://…`），也可以是相对地址（`/uploads/a.png`）；
- **第二行起**写图注，会渲染成灰色小字，并且跟随图片的对齐方式；
- 点「**上传图片**」可以选本地文件上传（需要你自己的后端，见 README 的「图片上传」一节；在线演示版没有后端，请手动填地址）。

> 贴进公众号前，图片地址必须是别人也能访问到的地址。本地路径（如 `C:\…`）或只在自己机器上能打开的地址，读者是看不到图的。

## 组合与复合：让长文章变短

- **组合**：收纳一组模块，导出时外面套一层虚线框版式（`<section>`），适合"产品亮点"这类卡片。
- **复合**：只收纳、不套框，导出时等于把内部模块原样铺平——**专门用来把长列表折叠起来**，列表看起来短，导出内容不变。

相关操作：

- 建组合 / 复合：底部下拉里选，或勾选多个同级模块后点「合并为复合模块」；
- 多选：点模块行左侧的勾选按钮，或 `Ctrl + 点击` 模块行；
- 「折叠全部 / 展开全部」按钮在文章结构标题右侧；
- 想解散容器：点模块行上的拆分按钮，内部模块会原样放回上一层。

## 调样式：改一处，全篇生效

点顶部「样式」，里面是一份可编辑的 CSS 文本，只认 `.选择器 { 声明 }` 这种写法：

```css
.p  { margin:14px 0; font-size:17px; line-height:1.85; }
.h2 { color:#2F5D50; border-left:4px solid #2F5D50; }
```

点「应用」后预览立即变化，导出也同步生效，并且**随工程一起保存**。点「填回默认」可恢复内置样式。

完整选择器清单见 [样式定制.md](样式定制.md)。

## 导出

点右上角「导出」，或直接用快捷键：

| 方式 | 说明 |
| --- | --- |
| 复制到公众号 | `Ctrl + Shift + C`。带样式的富文本，粘进公众号编辑器即可保留排版 |
| 复制 HTML | 拿到完整的内联样式 HTML，贴到支持 HTML 的地方 |
| 复制纯文本 | 只要文字，去掉所有排版 |
| 下载 .html | 存成一个独立网页文件 |
| 导出 Word | 生成 `.doc`，可在 Word 里继续编辑 |
| 导出 PDF | 走系统打印窗口，选「另存为 PDF」；打印时只会输出正文 |

细节与常见问题见 [导出与粘贴公众号.md](导出与粘贴公众号.md)。

## 工程与存档

- 编辑过程**自动存在浏览器本地**（localStorage），刷新、关掉再开都还在；
- `Ctrl + S` 保存成 `.ptai.json` 文件，`Ctrl + O` 打开；也可以把 json 文件直接拖进页面打开；
- 换电脑、换浏览器、清缓存之前，记得存一份 `.ptai.json`；
- 「重置」会清空模块池与文章结构（可 `Ctrl + Z` 撤销），自定义样式会保留。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Z` / `Ctrl + Shift + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + S` / `Ctrl + O` | 保存 / 打开工程 |
| `Ctrl + Shift + C` | 带样式复制到公众号 |
| `Ctrl + P` | 导出 PDF |
| `Ctrl + Enter` | 输入框里直接排入 |
| `Ctrl + 点击模块行` | 多选 |
| `Enter` / `Delete` / `Ctrl + D` | 展开收起 / 删除 / 复制一份 |
| `Alt + ↑ ↓` | 上移 / 下移 |
| `Alt + →` / `Alt + ←` | 收进上方组合 / 从组合移出 |
| `Esc` | 取消多选 / 关闭弹窗 |

## 常见问题

**预览里看着好好的，粘到公众号就变了？**
公众号编辑器会对粘贴内容做二次处理（补边距、改标签）。以公众号里的最终效果为准微调样式，或者用「复制 HTML」。

**对齐点了没反应？**
先确认点的是格式条里的对齐按钮（展开模块后才看得到），再看预览区是否变化。如果只有标题不生效，是历史版本的引号截断 bug，请更新到最新版 `index.html`。

**缩进只缩了第一行？**
旧版本用 `<br>` 换行，`text-indent` 只作用于第一行。新版会把多行拆成多个 `<p>`，每行都缩进，请更新。

**内容不见了？**
localStorage 是按浏览器 + 域名隔离的。换了浏览器、用了隐私模式、清过缓存，之前的草稿就找不到了——这也是为什么要用 `.ptai.json` 存一份。
