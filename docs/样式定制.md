# 样式定制

排版台的样式集中在一张内部样式表 `S` 里。点顶部「样式」就能看到它的全部内容（以 CSS 文本形式呈现），改完点「应用」，**预览与导出同时生效**，并随工程一起保存。

## 默认样式一览

这些就是内置默认值，也是你打开样式面板时看到的初始文本：

| 选择器 | 作用 | 默认值 |
| --- | --- | --- |
| `.wrap` | 全篇容器：字号 / 行高 / 字色 / 字体 | `font-size:17px;line-height:1.75;letter-spacing:.05em;color:#3F3F3F;font-family:-apple-system,BlinkMacSystemFont,'PingFang SC','Microsoft YaHei',sans-serif;` |
| `.h1` | 一级标题 | `font-size:22px;line-height:1.5;font-weight:700;color:#C0392B;margin:28px 0 14px;letter-spacing:.02em;font-family:'Songti SC','Noto Serif SC','SimSun',serif;` |
| `.h2` | 二级标题 | `font-size:20px;line-height:1.5;font-weight:700;color:#2B4C7E;margin:26px 0 12px;padding-left:10px;border-left:4px solid #2B4C7E;letter-spacing:.02em;font-family:'Songti SC','Noto Serif SC','SimSun',serif;` |
| `.h3` | 三级标题 | `font-size:18px;line-height:1.5;font-weight:700;color:#5F7A52;margin:20px 0 10px;letter-spacing:.02em;` |
| `.p` | 正文段落 | `margin:14px 0;` |
| `.strong` | 重点段落（整段加粗） | `margin:14px 0;font-weight:700;color:#17191C;` |
| `.quote` | 引用块 | `margin:16px 0;padding:12px 14px;background:#F7F7F5;border-left:4px solid #6B4E8C;color:#5A6169;font-size:16px;` |

| `.hr` | 分割线 | `border:none;border-top:1px dashed #D6D9DD;margin:26px 0;` |

## 写法规则

只认一种写法，注释随意（`/* … */`）：

```css
/* 说明文字 */
.选择器 {
  声明: 值;
  声明: 值;
}
```

- 不认识的选择器会被忽略（可用的就是上表那 17 个）；
- 同一选择器写多次，后面的覆盖前面的；
- 把面板清空并「应用」，等于恢复全部默认样式；
- 面板里的内容随工程（`.ptai.json`）一起保存，换机器也能带走。

## 实用示例

**换主色（墨绿系）**

```css
.h1 { color:#2F5D50; }
.h2 { color:#2F5D50; border-left:4px solid #2F5D50; }
.h3 { color:#4A7A66; }
.quote { border-left:4px solid #2F5D50; }
```

**正文更疏朗，适合长文阅读**

```css
.wrap { font-size:17px; line-height:1.95; letter-spacing:.06em; color:#33383D; }
.p { margin:18px 0; }
```

**图片带圆角与浅边**

```css
.img { border-radius:8px; border:1px solid #E7E8EA; }
.cap { font-size:13px; color:#9AA0A6; }
```

**卡片式组合外框**

```css
.box { margin:18px 0; padding:16px 16px; background:#F7F9FB; border:1px solid #E1E6EC; border-radius:10px; }
```

**分割线换成实线细线**

```css
.hr { border-top:1px solid #E7E8EA; margin:30px 0; }
```

## 三个必须注意的坑

**1. 样式值里不要用双引号**

导出的样式是塞进 HTML 属性里的：`style="…"`。如果你写成

```css
.h1 { font-family:"Songti SC",serif; }
```

浏览器解析到 `font-family:` 就会认为属性结束，**后面所有声明全部失效**（这正是早期版本标题无法居中、无法右对齐的原因）。请一律用单引号：

```css
.h1 { font-family:'Songti SC',serif; }
```

即便你忘了，程序也会在应用样式时把双引号替换成单引号兜底。

**2. 单位要写全**

`font-size:17` 这类缺单位的写法在浏览器里会被忽略，请写 `17px`。

**3. 图片宽度靠 `.img` 控制**

图片默认 `max-width:100%`，宽度跟随容器。想固定宽度就改 `.img`（例如加 `width:100%;`），对齐方式仍由「位置」按钮写在外框的 `text-align` 上。
